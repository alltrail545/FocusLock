# FocusLock 🔒

একদম কড়া স্ক্রিন-টাইম লক অ্যাপ — নির্ধারিত সময়ে তুমি চাইলেও ফোন ব্যবহার করতে পারবে না।

নিজের ফোনের জন্য, নিজের নিয়মে। কোনো অ্যাকাউন্ট নেই, কোনো সার্ভার নেই, কোনো ডেটা ফোনের বাইরে যায় না।

## ফিচার (v1.0.0)

- **লক শিডিউল** — যেমন রাত 11:00 → ভোর 5:00, বা পড়ার সময়। ওই সময় পুরো ফোন লক; শুধু জরুরি কল আর অ্যালার্ম চলবে। ওভারনাইট শিডিউল (মাঝরাত পার হয়ে) সাপোর্ট করে।
- **ফোকাস সেশন** — 25 / 60 / 120 মিনিট। একবার শুরু করলে সময় শেষ হওয়ার আগে বাতিল করার কোনো বোতামই নেই।
- **অ্যাপ লিমিট** — প্রতিদিনের সীমা (যেমন YouTube দিনে 30 মিনিট)। সীমা পার হলে অ্যাপ সেদিনের জন্য বন্ধ — Device Owner মোডে অ্যাপটা সত্যিকার অর্থে suspend (disable-এর মতো) হয়ে যায়, পরদিন নিজে থেকেই খোলে।
- **24 ঘণ্টার নিয়ম** — সুরক্ষা দুর্বল করে এমন যেকোনো পরিবর্তন (শিডিউল মোছা, লিমিট তোলা/বাড়ানো, Protection Off) PIN দেওয়ার পরও **24 ঘণ্টা পরে** কার্যকর হয়। তাৎক্ষণিক আবেগে কিছুই ভাঙা যায় না। Pending পরিবর্তন সবসময় স্ক্রিনে দেখা যায় এবং PIN দিয়ে বাতিল করা যায়।
- **ট্যাম্পার লগ** — ভুল PIN, লক স্ক্রিনে Back চাপা, Admin বন্ধ করার চেষ্টা — সব লগ থাকে।

## কেন এটা সত্যিই কড়া? (Device Owner)

সাধারণ অ্যাপ চাইলে আনইনস্টল করে ফেলা যায় — তাই FocusLock বানানো হয়েছে **Device Owner** মোডের জন্য। Device Owner হলে Android নিজে এই সুরক্ষাগুলো দেয়:

- FocusLock **আনইনস্টল করা যাবে না**, Force Stop / Clear Data-ও না
- **Safe Mode**-এ ঢোকা বন্ধ (Safe Mode দিয়ে অ্যাপ অকেজো করার পথ বন্ধ)
- Settings থেকে **Factory Reset** বন্ধ
- **তারিখ/সময় বদলানো** বন্ধ + Auto-time বাধ্যতামূলক (ঘড়ি ঘুরিয়ে শিডিউল ফাঁকি দেওয়া যাবে না)
- USB Debugging বন্ধ
- লক চলাকালে **LockTask (kiosk) মোড** — Home/Recent বোতামে কোথাও যাওয়া যায় না; লক স্ক্রিনই পুরো ফোন

### সৎ সীমাবদ্ধতা

ফিজিক্যাল Recovery Mode থেকে ফ্যাক্টরি রিসেট বা ফোন ফ্ল্যাশ করা কোনো অ্যাপই আটকাতে পারে না — এটা Android-এর হার্ডওয়্যার-স্তরের পথ। দৈনন্দিন ব্যবহারে, আবেগের মুহূর্তে, ফোন হাতে থাকা অবস্থায় bypass করার সব সফটওয়্যার-পথ বন্ধ — সেটাই এই অ্যাপের কাজ।

## সেটআপ (একবারই)

> ⚠️ Device Owner বসানোর শর্ত: ফোনে **কোনো Google/অন্য অ্যাকাউন্ট যোগ করা থাকা যাবে না**। সবচেয়ে সহজ উপায় — ফ্যাক্টরি রিসেটের পর, কোনো অ্যাকাউন্ট যোগ করার আগেই নিচের ধাপগুলো করা। দ্বিতীয় ফোন/পুরনো ফোনে প্রথমে টেস্ট করা বুদ্ধিমানের কাজ।

1. APK ইনস্টল করো (GitHub Actions artifact / Release থেকে)।
2. PC-তে [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools) ইনস্টল করে ফোনে USB Debugging চালু করো (Developer Options থেকে) — Device Owner বসানোর *আগ পর্যন্ত* এটা করা যায়, বসানোর পর Debugging নিজে থেকেই বন্ধ হয়ে যাবে।
3. PC থেকে চালাও:
   ```
   adb shell dpm set-device-owner com.focuslock.app/.AdminReceiver
   ```
   সফল হলে দেখাবে: `Success: Device owner set to package com.focuslock.app`
4. FocusLock খুলে বাকি অনুমতিগুলো দাও: Device Admin, Accessibility, Usage Access, Overlay।
5. PIN সেট করো (ভুলে গেলে ফ্যাক্টরি রিসেট ছাড়া উপায় নেই — সাবধানে রাখো)।
6. শিডিউল / লিমিট বসাও।

Device Owner ছাড়াও অ্যাপ চলবে (Accessibility + Overlay ব্লকিং), কিন্তু তখন আনইনস্টল করে bypass করা সম্ভব — কড়া মোডের জন্য Device Owner আবশ্যক।
